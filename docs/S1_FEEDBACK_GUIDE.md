# 智学探险家 S1 反馈指南

## 学生反馈问题

1. 你觉得这个像不像游戏？
2. 你最喜欢哪个部分？
3. AI 提示有没有帮到你？
4. 错题怪兽有没有让你想复盘？
5. 你愿不愿意明天再玩一次？

## 家长反馈问题

1. 你能否看懂成长报告？
2. 你觉得这个产品是在学习还是在玩？
3. 你最担心什么？
4. 你愿不愿意让孩子连续使用一周？
5. 如果后续完善，你是否愿意付费？

## 观察指标

- 完成一次体验所需时间
- 学生是否主动点击“开始挑战”
- 学生是否主动请求 Nova 提示
- 学生看到错题怪兽时的反应
- 学生是否能理解成长报告
- 家长是否认为学习价值明确

## 记录方式

- 观察者记录学生操作中的卡点
- 让学生口头回答反馈问题
- 让家长看完成长报告后回答反馈问题
- 将 `/feedback` 页面复制出的模板粘贴到微信、飞书或文档中保存
