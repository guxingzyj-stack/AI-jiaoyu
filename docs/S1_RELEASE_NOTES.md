# 智学探险家 S1 试映发布说明

## 当前版本已实现

- `/pilot` 第一季试映入口页
- `/adventure` 今日冒险和每日任务
- `/challenge` 本地数学题挑战
- Nova AI 三层提示：思路提示、关键步骤、完整讲解
- `/monsters` 错题怪兽图鉴、复盘、击败
- `/skills` AI 技能卡
- `/report` 今日成长报告
- `/feedback` 试映反馈模板
- localStorage 体验数据保存
- 每日任务、连续学习、题目轮换、重置体验数据

## 当前版本限制

- 数据仅保存在当前浏览器 localStorage
- 题库是本地 mock 数据
- AI 回复默认是 mock，不接真实 OpenAI API
- 没有登录、数据库、OCR、支付、教师端或家长端
- 不支持 PDF 导出或反馈后台提交

## 重要说明

本版本是早期试映版，不代表最终产品形态。试映重点是验证：

- 孩子是否愿意用游戏方式完成学习任务
- AI 分层提示是否比直接给答案更适合学习
- 错题怪兽是否能提升复盘意愿
- 成长报告是否能让家长理解学习价值

## 第二季计划方向

- 接入真实 OpenAI API
- 增加更多题型和同类题生成
- 增加账号和云端同步
- 完善家长报告
- 增加连续学习和阶段成长体系
