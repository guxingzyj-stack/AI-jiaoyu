# S3 Narrative Bible：星光唤醒世界观

## 1. S3 总原则

S3 的体验顺序是：

1. 先游戏
2. 再学习
3. 再练习

S3 不是“做题包装成游戏”。

S3 要做的是：“游戏冒险中必须使用数学力量继续前进”。

孩子不是为了完成题目而进入游戏，而是在游戏世界里遇到需要动脑筋解决的处境。数学不是外部插入的测验，而是推动角色、机关、岛屿和星光变化的力量。

## 2. 世界主线

数学星球的星光正在一座座岛屿上熄灭。

瞌睡迷雾正在蔓延。它让能量树睡着、数字精灵迷糊、机关停转。

Nova 是星球的小守护者。孩子是愿意和 Nova 一起动脑筋的小伙伴。

孩子和 Nova 一起，用数学力量重新点亮数学星球。

## 3. 价值观规则

数学不是攻击、消灭、打败的武器。

数学是点亮、唤醒、修复、驱散迷雾的力量。

游戏中不使用以下攻击性表达：

- 敌人
- 消灭
- 击杀
- 打死
- 攻击

被阻挡的角色不是坏人，而是被瞌睡迷雾困住的小精灵。

孩子做的是救醒、帮助、唤醒。

## 4. Nova 定位

Nova 不是普通提示按钮。

Nova 是伙伴、朋友、老师。

Nova 陪孩子探索、提醒、鼓励、总结。

Nova 和孩子的关系会逐步变化：

1. Nova 带着孩子走
2. 孩子和 Nova 并肩行动
3. 孩子走在前面，Nova 跟着
4. 孩子成为数学星球的小守护者，Nova 成为可随时召唤的伙伴

## 5. 低龄剧情原则

剧情不是大段文字对白。

剧情靠处境、危机、角色、画面变化来演出来。

对 6 年级以下孩子，要少文字、短句子、强视觉反馈。

世界从暗到亮，就是最重要的剧情反馈。

## 6. 三层剧情结构

### 世界层

星光熄灭，瞌睡迷雾蔓延，孩子和 Nova 拯救数学星球。

### 岛屿层

每座岛从沉睡 / 变暗，到被点亮 / 复苏。

### 遭遇层

每个事件都是救醒一个被困的小精灵或修复一个机关。

## 7. S3E1 方向

名称：`森林小路 · 星光唤醒`

S3E1 不是“打怪破盾”。

S3E1 是“动手凑数，驱散瞌睡迷雾，救醒小精灵”。

核心动作：

- 两个数字能量球合成 10
- 如果合成 10，迷雾散开，小精灵醒来，森林变亮
- 如果没合成 10，能量球弹回，Nova 温和提醒

## 8. 禁止词与推荐词

### 禁止

- 打怪
- 击败
- 攻击
- 消灭
- 敌人
- 杀
- 血量

### 推荐

- 唤醒
- 点亮
- 修复
- 驱散迷雾
- 救醒小精灵
- 星光碎片
- 成为朋友
- 森林重新亮起来

## 9. GPT Image 资产方向

S3 视觉资产方向：

- 统一深蓝宇宙、3D 儿童科幻游戏风格
- Nova 机器人伙伴
- 数学星球 / 漂浮岛
- 蓝紫霓虹
- 金色星光
- 灰蓝瞌睡迷雾
- 小精灵从沉睡到醒来
- 岛屿从暗到亮
- 温暖、低龄、无暴力

## 10. 后续开发规则

所有 S3 开发任务必须先读取本文件。

S3E1 `/adventure/forest-rpg` 必须遵守本叙事规则。

不允许把 S3 做成“选择题 + 游戏皮”。

数学动作必须尽量成为孩子实际操作的游戏动作。
