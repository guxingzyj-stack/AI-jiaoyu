# S1.5 Tutorial Island RC 试映脚本

## 试映对象

小学 2-4 年级孩子优先。

## 体验时间

建议 5 分钟。

## 推荐路径

```text
/pilot → /adventure → /challenge → /report
```

## 观察重点

1. 孩子是否知道要点云朵。
2. 孩子点亮第一颗星后，是否愿意继续小挑战。
3. 孩子是否听 Nova 的引导，能否跟着看 24 拆成 20 和 4。
4. 孩子是否看懂星星报告里的贴纸结果。
5. 孩子是否愿意明天再玩。

## 试映记录建议

- 不要先讲太多规则，让孩子自己看入口。
- 如果孩子 10 秒内不知道点哪里，只提示一句：“看看 Nova 让你做什么。”
- 记录孩子在哪一步停住、笑了、主动点击或想退出。
- 试映结束后，让孩子说一个最喜欢的地方。
- 家长只需要判断：这是否像一个孩子愿意继续玩的学习小冒险。

## 通过标准

- 孩子能在 5 分钟内走到星星报告。
- 孩子能理解“点云朵”和“继续小挑战”。
- 孩子不会被大量文字或复杂按钮卡住。
- 家长能在报告页 5 秒内看懂今天完成了什么。
