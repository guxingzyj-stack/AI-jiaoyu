### 第一章：睡着的森林

路由：

`/adventure/forest-map`

主题：

孩子和 Nova 进入沉睡森林，救醒三位森林朋友，修复森林星光循环，唤醒星光种子。

核心机制：

- 小地图探索
- 去果园准备能量果
- 凑十机关
- 平衡机关
- 数字规律机关
- 三位森林朋友有能力
- 森林核心需要 3 位朋友 + 3 片碎片
- 完成后森林醒来

### 第二章：星光海 · 跳岛航线

路由：

`/adventure/starlight-sea`

主题：

孩子驾驶小船按节奏跳岛，修复星光海航线，点亮海星灯塔。

核心机制：

- 地图节点
- 二步跳岛：孩子先选 1/2/3 拍，选 2 拍才点亮 2、4、6、8
- 三步航线：孩子先选 2/3/4 拍，选 3 拍才点亮 3、6、9、12
- 海星灯塔：选择 4 拍节奏
- 漩涡门：找 2 拍与 3 拍航线的第一个共同落点 6
- 灯塔核心：放入 3 片星潮碎片
- 完成后进入第三章几何山
